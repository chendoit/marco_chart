### MLIT API 補充（2026-10-15）

針對 MLIT API 資料特性，使用時必須遵循以下三大規則與特性限制：

1. **最新 1–2 季資料之「暫定值」特性**（**已驗**）：
   - 申報落後期客觀存在：2026Q1 東京都 XIT001 成交筆數為 11,993 筆，僅為 2025Q4（16,401 筆）的 73.1%，純土地筆數更僅剩 358 筆（為前季之 36.7%）。此現象乃買受人問卷調查與不動產移轉登記之行政滯後，並非市場流動性驟降。
   - 實務操作規則：最新 1–2 季在圖表繪製時必須標記為「暫定值」或採用虛線呈現；每季執行常態抓取時，應同時回溯覆蓋更新前兩季之數據。
2. **出處標示與免責聲明法定要求**（**已驗**）：
   - 依據國交省《公共データ利用規約 1.0》（PDL 1.0，相容 CC BY 4.0）及 API 利用規約第 7 條，對外發布或提供服務時必須完整標示出處與免責條款：
     - 出處標示：`出典：国土交通省 不動産情報ライブラリ（https://www.reinfolib.mlit.go.jp/）`
     - 加工標記：「『不動産取引価格情報』（国土交通省）をもとに○○作成」
     - 服務免責聲明：「このサービスは、国土交通省の不動産情報ライブラリのAPI機能を使用していますが、提供情報の最新性、正確性、完全性等が保証されたものではありません。」
3. **抓取請求預算與連線規範**（**已驗**）：
   - API 無硬性頻率上限，但實測要求每次請求間隔必須 ≥ 1.0–1.5 秒，單次請求 timeout 設為 60 秒。
   - 全國抓取採用「年×都道府縣」架構（2005–2026 約 1,034 次請求，耗時約 38 分鐘，筆數約 580 萬筆）；三大都市圈起步僅需 66 次請求（約 3.5 分鐘）。
   - 金鑰安全：金鑰僅限登記者使用，連續 3 年無呼叫會被官方廢止，且嚴禁寫入任何公開代碼庫或前端應用。
