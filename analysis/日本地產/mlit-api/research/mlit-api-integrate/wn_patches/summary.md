## 插入位置：## 5. 這次研究沒有回答的問題（後）

### MLIT API 補充（2026-10-15）

針對原研究「沒有回答的問題」，對照 MLIT API 能力進行逐項檢驗，評估哪些現已有解、哪些仍無法解答：

1. **現已有解的問題**：
   - **「建売戸建平均價格缺乏一手序列」**（**已解，已驗**）：
     - 透過 XIT001 篩選「宅地(土地と建物)」且屋齡 ≤1 年，成功構建首都圈四縣連續 21 季的建売總價中位數序列（`shutoken_kenuri_proxy_quarterly.csv`）。證明總結 WN 提到的 4,825 萬（REINS 新築戶建手抄）與規劃 WN 提到的約 4,500 萬，與實測中位數（2025 年 4,400–4,600 萬圓）口徑高度一致，此代理序列完全可靠可程式化。
   - **「地價年度序列的全國性取得」**（**已解，已驗**）：
     - 放棄耗時數十小時且極易被封鎖的 XPT002 瓦片爬取方案，改採國土數值情報 `L01` 地價公示整檔直接解析（免金鑰），已完整計算 2016–2026 年東京、大阪、愛知、福岡、北海道之標準地變動率（`l01_city_yoy_annual.csv`）。
2. **仍沒有解的問題（MLIT 補不上）**：
   - **「首購族負擔能力量化（月付占所得比）」**（**仍未解，已驗**）：
     - MLIT 僅提供物件成交價，**完全不包含買方所得、貸款成數或家族年收**。年收倍率（東京カンテイ）依然缺乏可程式化的一手來源。
   - **「建設工事費デフレーター 2026-07 跳升 (+7.3%)」**（**仍未解，已驗**）：
     - 屬於建設營造統計範疇，MLIT API 不提供營造工程造價細項，仍需待國交省更新基準說明或原始 Excel 查證。
   - **「收益型不動產利差、租金與空置率」**（**仍未解，已驗**）：
     - MLIT 交易庫不含租賃契約與預期收益率（Cap Rate），三鬼商事辦公室租金與 JREI 期待利回り仍必須維持原本之獨立資料源。

## 插入位置：## 6. 數據可信度提醒（後）

### MLIT API 補充（2026-10-15）

引用 MLIT API 與國土數值情報數據時，必須特別注意以下三項數據特性，避免誤讀市場訊號：

1. **最新 1–2 季數據為「暫定值」，落後期約 2–3 季才收斂**（**已驗**）：
   - 2026Q1 東京都 XIT001 成交筆數僅 11,993 筆（為 2025Q4 16,401 筆之 73.1%），純土地筆數更驟降至 358 筆（僅 36.7%）。此落後乃登記與問卷回收之常態滯後，切勿解讀為需求急凍。初次發布數據在後續 2 季會持續回補收斂。
2. **問卷調查申報之母體涵蓋率約三成**（**待驗**）：
   - XIT001 之「不動產取引價格情報」係向法務局所有權移轉登記之買受人發放紙本/線上問卷，屬自願填報之行政調查，據前輪調研回收率約 30%~33%（待驗）。雖然物件數龐大（累積逾 540 萬筆），但存在一定之填報抽樣偏誤。自 2021 年起加入之房仲「成約價格情報」則有效提升了中古公寓之覆蓋率。
3. **屋齡與區域結構變動對中位數的干擾（結構效應）**（**待驗**）：
   - 未經控制的單純中位數單價會受到成交物件屋齡老化的負向拉扯。前輪實測顯示，東京 23 區中古公寓 2021Q1→2025Q4 未控制中位數漲幅為 +28.6%，而固定屋齡權重後實質漲幅達 +36.6%（結構效果壓低約 −8 個百分點）。分析長期房價漲幅時，建議同時呈現未控制中位數與固定屋齡權重序列。
