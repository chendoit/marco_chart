### MLIT API 補充（2026-10-15）

針對 T2 主題中「要驗證」項目（中古成約件數、新舊價差、中古成交單價走勢），MLIT API（`XIT001`）提供了微觀物件級的成交母體，可補足並交叉驗證現有 REINS 序列：

1. **首都圈中古公寓季度單價與成約量（已驗）**：
   - 透過 XIT001 篩選東京、神奈川、埼玉、千葉之「中古マンション等」，取得 2021Q1–2026Q1 連續 21 季成交資料（見 `reins_vs_xit001_overlap.csv`）。
   - 水準值：首都圈每㎡單價中位數由 2021Q1 的 55.7 萬圓上升至 2025Q4 的 70.8 萬圓，與 REINS 季度加權單價（71.6 萬 → 84.2 萬圓）呈高度同步走勢，**水準相關係數達 0.9424**（已驗）。
   - 趨勢值：兩者季度 YoY 年增率相關係數達 **0.7591**（已驗），證明 XIT001 能高度反映中古公寓之真實價格動能。
   - 口徑差異：XIT001 單季筆數為 REINS 成約筆數之 **1.77–1.90 倍**（已驗，2025Q4 XIT001 為 23,266 筆 vs REINS 12,632 筆）。主因 XIT001 不僅涵蓋 REINS 仲介成交（成約価格情報），亦納入買受人所有權移轉登記之問卷申報（不動產取引價格情報），母體涵蓋面更廣。
2. **MLIT 補不上的缺口（嚴格警示）**（**已驗**）：
   - **在席存量／在庫件數與在庫月數**：MLIT 僅記錄「已完成交易」之流量，**完全無市場待售存量（在庫）資料**。衡量買方是否開始挑屋、業者庫存周轉壓力，仍必須依賴東日本 REINS 的在庫月數（2026-08 為 14.6 個月，待驗）。
   - **新築マンション平均單價與發售戶數**：MLIT 無新成屋大樓初次發售統計，新築發售戶數與均價仍需依賴不動產經濟研究所（REEI）月度調查（待驗）。
