## 腳本

| 腳本 | 輸出 | 需要 |
|---|---|---|
| `fetch_prices.py` | prices_daily.csv | `.env` FED_API_KEY、EIA_API_KEY |
| `fetch_eia.py` | eia_dist_weekly.csv、eia_dist_monthly.csv | EIA_API_KEY |
| `fetch_hdd.py` | hdd_daily / hdd_5y / hdd_forecast / hdd_noaa_cpc.csv | 無 |
| `fetch_gas_storage.py` | gas_storage_eu.csv、gas_storage_eu_5y.csv | **GIE_API_KEY（缺）** |
| `fetch_lng_freight.py` | lng_freight.csv、lng_freight_audit.csv、baltic_gas_reports.json（快取） | Spark 選用：SPARK_CLIENT_ID/SECRET |
| `build_derived.py` | derived_daily.csv | 先跑 fetch_prices、fetch_lng_freight |

> 同資料夾的 `fetch_data.py` / `analyze.py` 及其輸出 `eia_weekly.csv`、`eia_daily.csv`、`yahoo_daily.csv`、`fred_monthly.csv` 是另一個 session 寫的，不在本清單範圍內。本清單的 EIA 輸出改名為 `eia_dist_*` 以免互相覆蓋。
