# 沒有日頻 haircut 時的替代指標與近似檢查

日期：2026-11-10。腳本：`analyze.py`（`venv\Scripts\python.exe substitute/analyze.py` 可重跑；只讀既有檔案，不抓外部資料）。

## 結論（先講）

1. **日頻代理和 Form PF 過度擔保率的同步方向，與「價差擴大＝haircut 收緊」的直覺相反。**
   可下結論（n ≥ 20 季）的相關幾乎都是**負**的：融資價差、利率分散度、DVP 部位越大的季，Form PF 過度擔保率越**低**。
2. 最強的單一同步是 `dvp_ov_to_tri_vol`（DVP 未平倉量／三方成交量），季末水準 r = −0.64（n = 33），季平均 r = −0.58（n = 33）。
   但季變動相關只剩 −0.18～−0.34，表示水準相關主要來自共同趨勢（2022 後 DVP 部位擴張、過度擔保率下降），不是季對季同步。
3. 季末值比季平均同步得好：可下結論列的 |r| 中位數，水準 0.40（季末）vs 0.16（季平均），變動 0.23 vs 0.13。
4. 建議組合（見下）季末水準 r = −0.59（n = 33）、季變動 r = −0.39（n = 32），**只可當作「經銷商中介壓力／槓桿需求」的價格面指標**，與 haircut 呈反向同步，**不是 haircut 的替代值**。
5. 沒有任何一個代理在分段（2018Q1–2022Q2、2022Q3–2026Q2）中符號與強度都穩定；`sofr_tgcr_bp` 在後段甚至翻成 +0.74（n = 16，未達 20 季，不下結論）。

## 為什麼方向是反的（解讀，不是證明）

- **組成效應**：Form PF 過度擔保率是「全體合格對沖基金 repo 借款」的加權平均。2022 年後基差交易擴張，大量部位走集中清算／贊助回購，這類國債 repo 的 haircut 很低甚至為 0。
  部位越大 → DVP 量與餘額上升、利差與分散度上升 → 同時把平均過度擔保率往下拉。代理量到的是「低 haircut 槓桿的規模」，不是「haircut 收緊」。
- **價格與擔保品的替代**：經銷商可以用利率或 haircut 收緊。數據顯示這段期間主要是利率端在調整（價差變大），haircut 端反而放鬆。
- **體制**：2020–2021 準備金充裕，價差與分散度很低；同期對沖基金在 2020 年 3 月去槓桿後過度擔保率偏高（18–21%）。單一體制差異就足以製造整段的負相關。

## 方法

- 參照：`repo_haircuts.csv` 的 `FPF-OCRATEALL_PERCENT`（主）與 `FPF-OCRATECASHSEC_PERCENT`（輔），2018Q1–2026Q2，34 季。
- 日頻代理聚合到季：
  - 季平均：季內至少 20 個有值交易日才計算（GCF 利率因此幾乎全部剔除）。
  - 季末：季內最後一筆可得值。
- 相關：Pearson 與 Spearman，分「水準」與「季變動」兩種。樣本少於 20 季的不下結論。
- 組合：`sofr_tgcr_bp`、`dvp_tri_bp`、`sofr_p75_p25_bp` 各自 z 分數後等權平均。選這三個的理由是**理論方向一致**（都是價格面的中介壓力），不是挑相關最高的，以避免在 88 組比較中挑到偶然結果。
- 沒有用季頻資料回推日頻 haircut。內插沒有依據。

## 限制與不能代表什麼

- **相關只代表同步，不代表可以互換。** 即使 |r| = 0.6，也只解釋約 36% 的季頻變異，而且主要是趨勢。
- 組合**不能**代表：某一天的 haircut 水準、haircut 的方向（它與 haircut 反向）、特定對手或特定擔保品的 haircut、非國債擔保品（Form PF 含其他擔保品）、未清算雙邊（NCCBR）市場的 haircut。
- 樣本只有 32–34 季且序列自我相關，有效樣本更少；|r| ≈ 0.35 是名目 5% 門檻，實際門檻更高。88 組比較中出現幾個 |r| > 0.4 也可能只是偶然（例如 `tri_vol_rel60_pct` 季變動 +0.47）。
- Form PF 本身是「全體對沖基金加權平均」，混合了 haircut 政策與部位組成，不是純粹的 haircut 收緊指標；用它當參照會把組成效應帶進來。
- `bgcr_tgcr_bp` 季末值常為 0、無變異，季末相關無法計算。

## 實務建議

- 日頻監控用組合（季末對齊最好）當「repo 中介壓力」指標；讀法是**壓力升高 ≈ 低 haircut 槓桿部位擴大**，這是 haircut 突然收緊時的脆弱度，不是收緊本身。
- haircut 本身仍只能等季頻 Form PF（落後約 2 季）與 SCOOS 的定性調查（`SCOOS-NET_COLLATTERMS`）。
- 若要進一步驗證，可把 F4 `hedge_fund_leverage.csv` 的 repo 借款規模放入，檢查組成效應解釋（未在本次執行）。
